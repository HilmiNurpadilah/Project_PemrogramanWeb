# Panduan Pengujian

## Skenario Dasar

1. Login sebagai admin dan pastikan dashboard admin tampil.
2. Login sebagai dosen dan pastikan mata kuliah yang diampu muncul.
3. Login sebagai mahasiswa dan pastikan dashboard mahasiswa tampil.
4. Coba akses halaman role lain secara langsung untuk memastikan ditolak.

## Pengujian Admin

- Tambah, edit, dan hapus data mahasiswa.
- Tambah, edit, dan hapus data dosen.
- Tambah, edit, dan hapus mata kuliah.
- Tambah, edit, dan hapus tahun akademik.
- Tambah, edit, dan hapus jadwal kuliah.

## Pengujian Dosen

- Lihat mata kuliah yang diampu.
- Lihat daftar mahasiswa per mata kuliah.
- Input nilai tugas, UTS, dan UAS.
- Pastikan nilai akhir, huruf, dan bobot terisi otomatis.

## Pengujian Mahasiswa

- Isi KRS pada tahun akademik aktif.
- Uji batas maksimal 24 SKS.
- Uji larangan memilih mata kuliah ganda.
- Hapus mata kuliah dari KRS sebelum dikunci.
- Kunci KRS.
- Lihat KHS, IPS, dan IPK.
