# Ringkasan Proyek

## Fitur Inti

- Login multi-role
- Dashboard admin, dosen, dan mahasiswa
- CRUD data master akademik
- KRS, KHS, IPS, IPK
- Input nilai dosen
- Proteksi akses berdasarkan role

## Struktur Data Utama

- `users`
- `mahasiswa`
- `dosen`
- `mata_kuliah`
- `tahun_akademik`
- `jadwal_kuliah`
- `krs`
- `detail_krs`
- `nilai`
