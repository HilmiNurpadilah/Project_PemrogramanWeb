# Fitur Admin

## Ringkasan

Admin berperan mengelola data master akademik dan memantau data operasional aplikasi.

## Fitur

- Dashboard admin dengan ringkasan data
- CRUD mahasiswa
- CRUD dosen
- CRUD mata kuliah
- CRUD tahun akademik
- CRUD jadwal kuliah
- Pengelolaan akun pengguna
- Aktivasi dan deaktivasi akun

## Catatan Operasional

- Semua proses CRUD memakai prepared statement.
- Akses dibatasi hanya untuk role admin.
