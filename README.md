# Sistem Informasi Akademik Berbasis Web

Proyek ini adalah aplikasi Sistem Informasi Akademik sederhana menggunakan PHP native dan MySQL.

Tahap awal yang sudah disusun:
- Analisis kebutuhan sistem
- Aktor dan hak akses
- Use case teks
- Alur proses Admin, Dosen, dan Mahasiswa
- Kebutuhan fungsional dan nonfungsional

Langkah pengembangan berikutnya akan mengikuti tahapan bertahap, mulai dari desain database, struktur folder, autentikasi, lalu fitur CRUD dan akademik.
